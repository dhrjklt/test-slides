Four tricks do all of it

Slides are sections

Only the active one is shown. The URL hash remembers where you are.

show(n): slides.forEach((s, i) =>
  s.classList.toggle('active', i === n));
history.replaceState(null, '', '#' + (n + 1));

Morphs are View Transitions

Matching names on two slides make the browser animate between them.

.frame, .bigbox { view-transition-name: pipeline; }
document.startViewTransition(() => show(n));

Step animations are a timeline

A list of delays and actions. Leaving the slide cancels it.

timeline([
  [600, () => setStep('transfer', 'running')],
  [900, () => log('copying 12 files…')],
]);

Simulations are a loop

Update a small state object, then redraw from it.

const id = setInterval(() => {
  arrive(); pack(); advanceJobs(); render();
}, 350);

Make it yours

Copy a section, change the story

  1. Duplicate a <section class="slide"> and edit its text and boxes.
  2. Give it data-anim="name" and add anims.name in the script.
  3. Present from the browser, or run node record.mjs to get an MP4.
